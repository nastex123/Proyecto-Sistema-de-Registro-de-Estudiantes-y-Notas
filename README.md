# Sistema de Registro Académico

Este proyecto implementa un sistema de gestión académica en Python que permite registrar estudiantes, asignar materias y notas, mostrar información detallada, calcular promedios y determinar al mejor estudiante. El programa funciona mediante un menú interactivo en consola.

## Características principales

- **Registro de estudiantes**: Permite agregar nuevos estudiantes evitando duplicados.  
- **Gestión de materias y notas**: Cada estudiante puede tener múltiples materias asociadas con sus respectivas calificaciones.  
- **Visualización de información**: Muestra la lista de estudiantes y sus materias con notas.  
- **Cálculo de promedios**: Calcula el promedio de cada estudiante en función de sus notas registradas.  
- **Mejor estudiante**: Identifica al estudiante con el promedio más alto.  
- **Menú interactivo**: Navegación sencilla mediante opciones numéricas.

## Requisitos

- Python 3.8 o superior.  
- No requiere librerías externas, únicamente la instalación estándar de Python.

## Ejemplo de ejecución

```
--- SISTEMA DE REGISTRO ACADEMICO ---
1 Registrar estudiante
2 Registrar materia y nota
3 Mostrar información de estudiantes
4 Calcular promedios
5 Mejor estudiante
6 Salir
Seleccione una opción:
```
